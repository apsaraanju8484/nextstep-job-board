# Nextstep — Job Discovery

A responsive job board concept made with HTML, CSS, and vanilla JavaScript.

## Features

- Search roles, companies, skills, and locations.
- Filter by department, remote/hybrid/on-site workplace, and job type.
- Sort jobs by recency or salary.
- View role details, team information, responsibilities, and perks.
- Save roles in localStorage for later.
- Application form preview with client-side interactions.
- Responsive desktop and mobile layouts.

## Run locally

Open `index.html` in a browser. No packages or build step are needed.

All companies, roles, and salary ranges are sample data for a portfolio demo. The sign-in and apply flows are front-end previews; form data is not sent to a server. Fonts load from Google Fonts.
